# R-101 — Rommel's Arrival: who wins when the Axis holds only Tobruk

## Problem

The Group Two victory case first says that whoever holds Tobruk at the end
wins, then gives the Axis decisive and strategic sets, and then says that
an Axis player holding less than the strategic set has lost. Read
literally, an Axis player holding Tobruk (or Tobruk and Bardia) both wins
and loses. The case also names a Commonwealth "smashing" victory, prints
no supply condition for any holding, and does not say what happens if
neither side holds Tobruk.

## Options

1. **Ladder.** Holding Tobruk is an Axis victory, adding Bardia a decisive
   one, the full set a strategic one; the "less than the above" sentence
   refers to failing to hold Tobruk. The Commonwealth wins by holding
   Tobruk, and smashingly with Bardia and Benghazi too.
2. **Strategic or nothing.** Only the full strategic set is an Axis win;
   anything less is a Commonwealth victory, and the first sentence is
   colour.

## Decision

Option 1. Holding Tobruk is an Axis victory, with Bardia a decisive one, with the full set a strategic one; an Axis player who does not hold Tobruk has lost, whoever (if anyone) holds it, and the Commonwealth wins smashingly with Tobruk, Bardia and Benghazi. No supply condition applies.

## Rationale

The case's first sentence, that whoever holds Tobruk wins, and its
decisive level, which only adds Bardia to Tobruk, both make sense only if
Tobruk alone is already an Axis win; the "anything less" sentence then
reads as the other side of the first, not as a cancellation of it. Option
2 would make two of the case's printed sentences dead text. An Axis player
without Tobruk holds "less than the above" whether or not the Commonwealth
holds it, so that is a Commonwealth victory too: no draw is printed. The
case prints no supply test, and none is added. The data already scores the
ladder this way.
