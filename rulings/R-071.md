# R-071 — May one rail run carry both units and supplies in the Logistics Game?

## Problem

Ruling [R-005](R-005.md) (accepted) reads the Land Game's rail cases so that
one rail stack in each direction may mix units and supplies. Case 54.31 says
the railroad moves either supplies or personnel, never both at once, and
54.32 adds that it may carry personnel one way and supplies the other.
54.33 further limits a supply run to one type of supply. So in the
Logistics Game the specific rule appears to forbid what R-005 allows.

## Options

1. **54.31 governs in the Logistics Game.** Each direction carries units or
   supplies (one type only), not both; R-005 stays as the Land Game reading.
   Consequence: the Logistics Game rail is more restrictive; R-005 needs a
   line saying so.
2. **R-005 governs in both games.** A run may mix units and supplies,
   within the 2-SP unit limit and the 1,500-ton supply limit (still one
   supply type, 54.33). Consequence: one rule for both games; 54.31's
   sentence is read as superseded by the later reading of 8.72.

## Decision

Option 1. In the Logistics Game each direction's rail run carries units or supplies (of one type), never both; R-005 remains the Land Game reading.

## Rationale

Case 54.31 is written for the Logistics Game and says in so many words
that the railroad moves supplies or personnel but not both together, and
54.32 confirms the split by letting men go one way while supplies go the
other. [R-005](R-005.md) read the Land Game's 8.72 "and/or" to allow mixed
loads because nothing else in the Land Game spoke to it; in the Logistics
Game a later, more specific case does, and it governs there. This is not a
break with R-005: R-005 still holds in the Land Game, and in the
Logistics Game the rest of it still applies (one run each way, loads may be
picked up and set down along the line within the limits, per 8.77 and
54.35); only the mixing of units and supplies in one run is barred.
Option 2 would have to treat a plain Logistics Game sentence as dead text.
See [Trucks and dumps — Rail](../rules/logistics/40-trucks-and-dumps.md).

Decided under Brian's delegation of 2026-09-26; open to dispute and
supersession like any ruling (see [rulings/README.md](README.md)).
