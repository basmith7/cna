# R-115 — Are there rating-5 pilots?

## Problem

40.15 lists four ratings from 1 up, then a 6 reserved for Marseille.
34.83 has pilot reinforcements rated from one to six arrive each month by
the Pilot Arrival Tables (34.88, 34.89). If those tables print a column for
rating 5, the two cases disagree; if they do not, 34.83 is loose wording.
The Pilot Arrival Tables are not yet transcribed.

## Options

1. **Whatever the Pilot Arrival Tables print.** A rating-5 pilot exists if a
   table can produce one; 40.15's list is then incomplete.
2. **No rating 5.** Follow 40.15: a 5 read from a table is an error, and
   such a pilot arrives as a 4.
