# R-182 — Blind barrage targets are numbered by class, not picked off the map

## Problem

12.23 has the barraged side answer only how many targets each adjacent hex
holds and the class of each (gun, armour, infantry); 12.24 has the firer
shoot "blind" at a numbered target of a class, such as infantry no. 2,
unless patrol or earlier combat has already identified a unit in the hex.
But 3.62's table lets a player examine any stack on the map, keeping only
the counters' contents secret. If examining a stack shows the firer each
counter, he could point at one, and 12.24's numbering would add nothing.
cna-engine, which today lets the firer name any counter, asked which
reading to enforce.

## Options

1. **Numbered by class.** The owner gives the hex's targets as a count per
   class and numbers each class for the barrage step, privately keeping
   which unit is which number; the firer picks a class and a number. He
   may name a unit only once its designation has been revealed to him, by
   patrol (16.51) or by earlier combat, as 12.23 allows. Seeing a stack on
   the map identifies nothing.
2. **Any counter on the map.** Examining the stack shows its counters, so
   the firer names whichever counter he likes; 12.24's numbering is not
   used. A dummy tank formation, which has no counter, could then never be
   fired at, and a mixed artillery unit (two targets under 3.22) would be
   one.
3. **A counter by position.** The firer points at a counter in the stack
   ("the third counter down") without learning what it is, and the owner
   tells him its class. Picks a physical counter without identifying it.

## Decision

Option 1. A blind barrage names a class and a number the owner assigned
for the step; a specific unit may be named only after patrol or earlier
combat has revealed its designation.

## Rationale

12.23 and 12.24 are the barrage rules' own word on what the firer is told,
and they withhold identity in so many words; 3.61 makes secrecy the
default, and 3.62's map entry keeps a counter's contents secret, so it
grants no identification the specific rules deny. Two printed rules show
that a target is not a counter: a dummy tank formation has no counter yet
is an armour-class target (12.22, 16.42), and an artillery or anti-tank
unit with both armoured and unarmoured points is two targets (note to
3.22). Under option 2 a hex's announced target count would exceed its
counters whenever a dummy sat there, exposing the deception 16.45 keeps
secret until an attack; option 3 has the same leak, since a dummy has no
position in the stack. Option 1 is the printed procedure, keeps both
cases working, and is simple to model: the owner's side holds the
number-to-unit map for the step, and the firer's choice is a class and an
index.

The numbering is fixed by the owner when he announces the targets and
holds for the whole barrage step, so every barrage at "infantry no. 2"
in that step hits the same unit (12.32's limit of one barrage per target
from each adjacent enemy hex counts against it). A Commonwealth warship is
always identified (the §32 addition to 12.23) and is named as itself.
