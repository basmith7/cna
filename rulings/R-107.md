# R-107 — "Active" and "inactive" dumps in the Crusader set-up

## Problem

Each side is given more dump sites than real dumps and told that only some
are active. 59.53 speaks of active and non-active dumps as real and dummy
ones, but it is not said whether an inactive site here is a dummy counter
or an empty real dump that can be filled later.

## Options

1. **Dummies.** Inactive dumps are dummy dumps (59.53); the data records
   them so.
2. **Empty real dumps.** They start empty but are real and can be stocked.
